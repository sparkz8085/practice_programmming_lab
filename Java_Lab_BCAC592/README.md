# Java OOP Lab — BCAC592

Nineteen independent Java programs based on the Object Oriented Programming with Java Lab index.

Compile and run an individual program:

```bash
javac 03_AddTwoNumbers.java
java AddTwoNumbers
```

For command-line argument exercises:

```bash
javac 01_CommandLineMaximum.java
java CommandLineMaximum 12 45 7 31
```

Requires Java 8 or later.
